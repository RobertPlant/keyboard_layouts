* Ergodox
EZ keymap for QMK. qmk comes from nixpkgs, kochanski has it installed along with the udev rules
for flashing (~hardware.keyboard.qmk.enable~).

Two switches are dead and set to ~KC_NO~ until I resolder them: the top left key of the left
thumb cluster and the key below backspace.

** Setup QMK
Link the keymap into the qmk checkout so there's nothing to copy across after each change.
#+begin_src bash
git clone git@github.com:qmk/qmk_firmware.git ~/qmk_firmware
cd ~/qmk_firmware && qmk setup
ln -sfn ~/projects/keyboard_layouts/ergodox ~/qmk_firmware/keyboards/ergodox_ez/keymaps/RobertPlant
#+end_src

Use ~nix shell nixpkgs#qmk~ anywhere qmk isnt installed.

** Compile
#+begin_src bash
qmk compile -kb ergodox_ez/base -km RobertPlant
cp ~/qmk_firmware/ergodox_ez_base_RobertPlant.hex ~/projects/keyboard_layouts/ergodox/ergodox_ez_RobertPlant.hex
#+end_src

** Flash
Press the reset button on the keyboard (or ~QK_BOOT~ on layer 3) when it asks. ~qmk flash~
needs the qmk_firmware checkout, this doesnt.
#+begin_src bash
nix shell nixpkgs#teensy-loader-cli -c teensy-loader-cli -mmcu=atmega32u4 -w -v ergodox_ez_RobertPlant.hex
#+end_src

** Keycaps
~keycaps/~ prints the YUZU keycap design for this keymap: UK legends, layer 1 in the corner,
the layer 2 numpad in blue and a purple cascade. Import ~ergodox-yuzu.json~ at
https://yuzukeycaps.com/keyboards/ergodox. Rerun it after changing the keymap.
#+begin_src bash
cd ~/projects/keyboard_layouts/keycaps
nix shell nixpkgs#cargo nixpkgs#rustc nixpkgs#gcc -c cargo run -q > ergodox-yuzu.json
#+end_src

* IBM Model M (Teensy)
Not working at the moment, the Teensy is dead and it went through a few of them so I think the
wiring needs checking before trying another one, ~docs/hardware.html~ has the Teensy wiring.

Runs Soarer's Converter, ~firmware/~ has the converter builds, ~docs/~ the docs and ~ibm.sc~ is
the layout. The tools (~scas~ to build the layout, ~scwr~ to write it) build from the source in
~tools/~.
#+begin_src bash
cd ~/projects/keyboard_layouts/ibm_m_8081
mkdir -p /tmp/sctools && python3 -m zipfile -e tools/Soarer_sctools_v1.10_source.zip /tmp/sctools
(cd /tmp/sctools/build/linux && nix-shell -p libusb-compat-0_1 --run make)
/tmp/sctools/bin/scas ibm.sc ibm.scb
/tmp/sctools/bin/scwr ibm.scb
#+end_src
